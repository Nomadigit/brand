# Icons

- **Set:** [Lucide](https://lucide.dev), outline only, stroke **1.75**, sizes 16 / 20 / 24.
  Packages: `lucide-react`, `lucide-static`. On Android use Lucide or Material Symbols Rounded at a matching weight.
- **Color:** `currentColor`, so an icon takes the color of its text. Only status icons use semantic colors.
- **Labels:** pair icons with text. Icon-only buttons need an `aria-label` and must be universally understood
  (close, search, menu, back).
- **Never:** filled or duotone sets, mixing icon families, emoji as UI icons.
